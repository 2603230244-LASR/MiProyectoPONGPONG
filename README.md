En este proyecto se irá trabajando con el versionamiento para mantener un orden y seguridad al ir modificando y creando el proyecto, el cual es un videojuego Pong Pong, el cual está dividido en 3 ramas: rama 1, actividad_uno, la cual es el primer trabajo que se realizó sobre Pygame, la escena; rama 2: actividad_dos, la cual contiene el código de la última actividad realizada en Pygame, el proyecto Pong Pong; y la rama 3: v01, que ya viene comenzando el versionamiento y modificación del código Pygame.
